# Weather App

## Description

Weather App is a responsive web application that provides real-time weather information and a 5-day weather forecast using the OpenWeatherMap API. 
Users can search for any city to view the current weather conditions, forecast details, and a dynamic background that changes based on the weather.

## Features

- Search weather by city name
- Displays current weather information
- Shows a 5-day weather forecast
- Dynamic weather backgrounds
  - ☀️ Sunny
  - ☁️ Cloudy
  - 🌧️ Rainy
  - ⛈️ Thunderstorm
- Displays:
  - Temperature
  - Weather Condition
  - Feels Like Temperature
  - Humidity
  - Wind Speed
- Shows an error message for invalid or unknown city names
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- OpenWeatherMap API

## API Used

- OpenWeatherMap API

## Output

- Search any city to view live weather details.
- Displays the current weather with location information.
- Shows a 5-day weather forecast.
- Changes the background based on the current weather condition.
- Displays an error message if the entered city is invalid.
